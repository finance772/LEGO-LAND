# 🧱 LEGO-LAND · מערכת ניהול מכירות לגו

מערכת PWA (אפליקציית רשת מתקדמת) לניהול מלא של שרשרת המכירות של חנות לגו —
מ**ביצוע ההזמנה**, דרך **חיוב והפקת קבלה**, **אריזה**, **משלוח**, ועד **דוחות וגביה**.
ניתנת להתקנה למסך הבית ולעבודה כאפליקציה אמיתית (גם אופליין).

הדשבורד פותח במסך **"דוד שלום"** ומציג בלייב את כל ההזמנות בתהליך ואת זמינות המלאי.

---

## ✨ יכולות עיקריות

| כפתור | מה הוא עושה |
|------|-------------|
| 📦 **עדכון מלאי** | העלאת רשימת פריטים למכירה (כמות לכל פריט) בהדבקה או טעינת קובץ CSV. הוספה / קביעת כמות מדויקת, והפקת **דוח תנועות ויתרות מלאי לאקסל**. |
| 🧾 **מצב הזמנות** | טבלה חיה: סטטוס, **זמן מאישור התשלום**, מק"ט, כמות בהזמנה וכמות זמינה במלאי — מתעדכן בזמן אמת. כולל אישור תשלום וקידום סטטוס. |
| 🎁 **אריזה** | כניסת אורז למשמרת (מספר ושם עובד), אריזת הזמנות, והדפסת **מדבקה הנושאת את קוד האורז** (לטיפול בתלונות) + זמן מאישור התשלום. |
| 🚚 **משלוח** | ניהול מערך ההובלה: כתובת, מוביל, מספר מעקב, וזמן מאז שההזמנה מוכנה. **הפקת קבלה אוטומטית ברגע שהמשלוח יוצא ללקוח.** |
| 📊 **דוחות** | (1) **יתרת מלאי לפי פריט** עם דריל-דאון למכירות לפי עסקאות שאושרו ע"י חברת האשראי. (2) **גביה אשראי** — דוח תקופתי לפי תאריכים, טעינת דוח הגביה מחברת האשראי, וסימון **כל אי-התאמה** בין דוח המכירות לדוח הגביה. |
| 🔗 **לינק הזמנה** | קליטת הזמנה חדשה המקושרת ישירות למלאי — עם אישור התשלום הכמות נגרעת אוטומטית. |

### השרשרת המלאה
```
לינק הזמנה → אישור תשלום (גריעת מלאי + עסקת אשראי) → אריזה (מדבקת אורז)
            → משלוח (הפקת קבלה) → נמסר   ⟵ הכל נמדד בזמן מאישור התשלום
```

המלאי מתעדכן **ברצף** לפי הזמנות שאושר תשלומן ולפי רשימות שמעדכן משתמש-על.

## 🚀 הפעלה

זוהי אפליקציית צד-לקוח סטטית. כדי שה-Service Worker וההתקנה יעבדו יש להגיש דרך HTTP:

```bash
# מתוך תיקיית הפרויקט
python3 -m http.server 8080
# ואז לפתוח בדפדפן:
#   http://localhost:8080/
```

או כל שרת סטטי אחר (`npx serve`, Nginx, GitHub Pages וכו').

### 📲 הורדה למסך הבית
- **אנדרואיד / כרום**: לחיצה על הכפתור **"⬇ הורד למסך הבית"** בראש המסך, או תפריט הדפדפן ← "התקן אפליקציה".
- **iPhone / Safari**: שיתוף ← "הוסף למסך הבית".

לאחר ההתקנה האפליקציה נפתחת במסך מלא, עם אייקון לגו, וזמינה גם ללא רשת.

## 🗂 מבנה הקבצים

```
index.html              מעטפת הדשבורד (RTL, עברית)
css/styles.css          עיצוב בנושא לגו
js/db.js                שכבת הנתונים והלוגיקה העסקית (localStorage)
js/excel.js             ייצוא לאקסל (SpreadsheetML) ופיענוח CSV
js/app.js               ממשק, ניווט, ועדכוני לייב
manifest.webmanifest    הגדרות PWA / התקנה
sw.js                   Service Worker (אופליין)
icons/                  אייקוני האפליקציה
```

## 💾 נתונים
- כל הנתונים נשמרים מקומית בדפדפן (`localStorage`) — אין צורך בשרת.
- בפתיחה ראשונה נטענים **נתוני הדגמה** (פריטי לגו, הזמנות לאורך כל השרשרת, ודוח גביה עם אי-התאמות לדוגמה).
- כפתור **"איפוס נתוני הדגמה"** בתחתית המסך מחזיר למצב ההתחלתי.

## 📥 פורמט קבצים לטעינה
- **רשימת מלאי**: עמודות `sku, name, barcode, price, qty` (גם בעברית: מק"ט, שם, ברקוד, מחיר, כמות). פורמט מהיר: `מק"ט,כמות` בכל שורה.
- **דוח גביה מחברת האשראי**: עמודות `txnId, amount` (אופציונלי `date, ref`).
